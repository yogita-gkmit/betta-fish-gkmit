## Topic Classification (BERT Chinese Base)

This directory provides a Chinese topic classification implementation using `google-bert/bert-base-chinese`:
- Automatically handles local/cached/remote three-stage loading logic;
- `train.py` for fine-tuning; `predict.py` for single or interactive prediction;
- All models and weights are uniformly saved to `model/` in this directory.

Reference Model Card: [google-bert/bert-base-chinese](https://huggingface.co/google-bert/bert-base-chinese)

### Dataset Highlights

- About **4.1 million** pre-filtered high-quality questions and answers;
- Each question corresponds to a "【Topic】", covering **about 28,000** diverse themes;
- Screened from **14 million** original Q&A, retaining answers with at least **3 likes**, ensuring content quality and interest;
- Besides questions, topics, and one or more answers, each answer also comes with like count, reply ID, and replier tag;
- After data cleaning and deduplication, divided into three parts: example split training set about **4.12 million**, validation/test sets (adjustable as needed).

> During actual training, please refer to the CSV under `dataset/`; the script will automatically identify common column names or allow explicit specification via command parameters.

### Data Format

CSV must contain at least a text column and a label column, the script will try to auto-identify:
- Text column candidates: `text`/`content`/`sentence`/`title`/`desc`/`question`
- Label column candidates: `label`/`labels`/`category`/`topic`/`class`

To specify explicitly, please use `--text_col` and `--label_col`.

### Training

```
python train.py \
  --train_file ./dataset/web_text_zh_train.csv \
  --valid_file ./dataset/web_text_zh_valid.csv \
  --text_col auto \
  --label_col auto \
  --model_root ./model \
  --save_subdir bert-chinese-classifier \
  --num_epochs 10 --batch_size 16 --learning_rate 2e-5 --fp16
```

Key Points:
- First run checks `model/bert-base-chinese`; if not present, tries local cache, then auto-downloads and saves;
- Training process evaluates and saves step-by-step (default every 1/4 epoch), keeping at most 5 recent checkpoints (adjustable via env var `SAVE_TOTAL_LIMIT`);
- Supports early stopping (default patience 5 evaluations), and auto-rollbacks to best model when evaluation/save strategies match;
- Tokenizer, weights, and `label_map.json` saved to `model/bert-chinese-classifier/`.

### Training Strategy (Brief)

- Backbone: `google-bert/bert-base-chinese`; Classification head dimension = number of unique labels in training set.
- Learning rate and regularization: `lr=2e-5`, `weight_decay=0.01`, can fine-tune to `1e-5~3e-5` on large datasets.
- Sequence length and batch: `max_length=128`, `batch_size=16`; if truncation is severe, can increase to 256 (higher cost).
- Warmup: If environment supports, use `warmup_ratio=0.1`; otherwise fallback to `warmup_steps=0`.
- Eval/Save: Steps calculated by `--eval_fraction` (default 0.25), `save_total_limit=5` limits disk usage.
- Early Stopping: Monitors weighted F1 (higher is better), default patience 5, improvement threshold 0.0.
- Single Card Stable Run: Defaults to using only one GPU, can specify via `--gpu`; script cleans distributed env vars.


### Author's Note (About Ultra-Large Scale Multi-Classification)

- When topic categories reach tens of thousands, appending a single linear classification head (large softmax) after the encoder is often limited: long-tail categories are hard to learn, semantic sparsity, new topics cannot be incrementally adapted, requires frequent retraining after launch.
- Improvement Ideas (Recommended Priority):
  - Retrieval/Two-Tower Paradigm (Text vs. Topic Name/Description Contrastive Learning) + KNN Retrieval + Small Head Re-ranking, natively supports incremental category expansion and fast updates;
  - Hierarchical Classification (Coarse then Fine), significantly reduces single head difficulty and computation;
  - Text-Label Joint Modeling (Using label descriptions), improves transferability of synonymous topics;
  - Training Details: class-balanced/focal/label smoothing, sampled softmax, contrastive pre-training, etc.
- Important Disclaimer: The "Static Classification Head Fine-Tuning" used in this directory serves only as an alternative and learning reference. For English/Multilingual micro-blogging scenarios, topics change extremely fast, traditional static classifiers struggle to cover timely. Our work focuses on Generative/Self-Supervised Topic Discovery and Dynamic System Construction directions like `TopicGPT`; this implementation aims to provide a runnable baseline and engineering example.
